WebKelasTIREGC - Portal Informasi Akademik
WebKelasTIREGC adalah portal informasi resmi kelas Teknik Informatika - Reguler C (Semester 7) Universitas Muhadi Setiabudi (UMUS). Aplikasi web statis dengan kapabilitas dinamis ini dirancang sebagai pusat komando terpadu untuk menyederhanakan akses terhadap jadwal perkuliahan, manajemen tugas akademik, dan pengumuman krusial secara real-time.
Fitur Utama
•	Sistem Manajemen Tugas Otomatis Sistem mengekstrak data batas waktu (deadline) berformat string dari basis data dan membandingkannya dengan waktu sistem lokal secara real-time. Tugas kemudian diklasifikasikan secara otomatis ke dalam status "Aktif" atau "Selesai".
•	Pengurutan Tugas Algoritmik Tugas yang berstatus aktif diurutkan secara dinamis untuk memprioritaskan tenggat waktu yang paling mendekati hari ini di posisi teratas. Tugas yang telah kedaluwarsa atau berstatus "Selesai" secara otomatis diberikan penyesuaian visual (redup) dan dipindahkan ke bagian paling bawah daftar.
•	Antarmuka Akordeon Interaktif Repositori tugas utama menggunakan antarmuka akordeon (buka-tutup) modular untuk merender detail instruksi penugasan. Hal ini secara signifikan menghemat ruang tampilan layar dan meningkatkan ergonomi keterbacaan data.
•	Sinkronisasi Dasbor Analitik Halaman beranda menampilkan dasbor statistik cerdas yang menghitung metrik secara real-time, meliputi total tugas, metrik penyelesaian, beban tugas berjalan, serta bilah kemajuan (progress bar) interaktif yang merepresentasikan pencapaian semester.
•	Widget Tugas Mendatang (Upcoming Tasks) Halaman beranda terintegrasi penuh dengan algoritma evaluasi waktu pada halaman tugas, sehingga komponen "Tugas Upcoming" secara eksklusif hanya menampilkan maksimal dua tugas aktif yang paling mendesak.
